# VFB Neurotransmitter Predictions

## Versions

### Stable release versions

The latest version of the ontology can always be found at:

http://virtualflybrain.org/data/VFB/OWL/VFB_NT.owl

### Editors' version

The edit version, [src/ontology/VFB_NT-edit.owl](src/ontology/VFB_NT-edit.owl), should not be changed manually - it is generated by an automated process.

## Information sources

For MANC, optic-lobe and male-cns datasets, predictions are sourced from the neuprint `predictedNt` field, with data generated by [Takemura et al. (2023)](https://doi.org/10.7554/eLife.97769.1), [Nern et al. (2025)](http://dx.doi.org/10.1038/s41586-025-08746-0) and [Berg (2025)](http://dx.doi.org/10.1101/2025.10.09.680999), respectively. Predictions for FlyWire FAFB and Hemibrain datasets are `conf_nt` from [Eckstein et al. (2024)](http://dx.doi.org/10.1016/j.cell.2024.03.016). BANC predictions are sourced from the `Predicted NT type` field of the Codex neurons.csv download and only used if not in conflict with the `Verified NT type` field, with data generated by [Bates (2026)](https://doi.org/10.1038/s41586-026-10735-w.).

In all cases, analysis was restricted to a particular set of neurotransmitters and assumed a single neurotransmitter per neuron (see publications for further detail). Neurons with fewer than 100 presynapses are excluded.
